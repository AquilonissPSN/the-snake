# the-snake
# 🐍 Проект «Изгиб Питона» (The Snake Game)

Полноценная 2D-игра **«Змейка»**, реализованная на языке Python с использованием библиотеки **Pygame** и принципов объектно-ориентированного программирования (ООП).

Проект разработан в рамках курса **«Python-разработчик»** от Яндекс Практикума.

---

## 🎮 Игровая механика и особенности

- **Управление**: классическое перемещение по сетке с помощью клавиш-стрелок (Вверх, Вниз, Влево, Вправо). Предусмотрена защита от случайного разворота на 180°.
- **Сквозной проход сквозь границы**: при выходе за пределы экрана змейка не погибает, а плавно появляется с противоположной стороны игрового поля.
- **Рост и генерация еды**: при поедании яблока длина змейки увеличивается на 1 сегмент, а новое яблоко генерируется в случайной свободной ячейке поля, гарантированно не попадая на тело змейки.
- **Столкновение с собой**: при попытке укусить собственный хвост игра автоматически сбрасывается к исходному состоянию (длина = 1, позиция в центре экрана).
- **Оптимизированная отрисовка**: стабильная работа на скорости 20 FPS с перерисовкой только изменившихся сегментов (стирание следа last).

---

## 🏗 Архитектура проекта

Проект построен по принципам чистого ООП и разделения ответственности:

- **GameObject**: абстрактный базовый класс для всех игровых объектов, инкапсулирует координаты позиции (position) и цвет (body_color), а также объявляет метод draw().
- **Apple**: класс яблока (наследник GameObject), отвечает за генерацию случайного положения на сетке 32x24 (randomize_position) и отображение на поле.
- **Snake**: класс змейки (наследник GameObject), управляет списком координат сегментов (positions), текущим и следующим направлением движения, перемещением (move), ростом и сбросом в начальное состояние (reset).
- **handle_keys()**: функция перехвата и обработки событий клавиатуры и закрытия окна приложения.
- **main()**: основной бесконечный цикл игры, координирующий взаимодействие объектов, обработку столкновений и обновление экрана.

## 🚀 Установка и запуск

### 1. Клонирование репозитория:
git clone https://github.com/AquilonissPSN/the-snake.git
cd the-snake

### 2. Создание и активация виртуального окружения:

На macOS и Linux:
python3 -m venv venv
source venv/bin/activate

На Windows:
python -m venv venv
source venv/Scripts/activate

### 3. Установка зависимостей:
pip install --upgrade pip
pip install -r requirements.txt

### 4. Запуск игры:
python the_snake.py

---

## 🧪 Тестирование и проверка качества кода

- Запуск автоматических тестов:
pytest

- Проверка стиля кода линтером Flake8:
flake8 the_snake.py
